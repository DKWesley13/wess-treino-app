# WESS TREINO — versão web (PWA)

Abra no celular: https://dkwesley13.github.io/wess-treino-app/

**iPhone:** abra no Safari → toque em Compartilhar → "Adicionar à Tela de Início".
**Android:** abra no Chrome → menu ⋮ → "Instalar app".

Funciona offline depois do primeiro acesso. Os dados de treino ficam somente no seu aparelho.

Este repositório contém apenas os arquivos estáticos do app (gerados a partir do projeto principal).
Créditos de terceiros: three.js (MIT, `vendor/three/LICENSE`), avatar e animações CC0 (`vendor/avatar/LICENCA.txt`),
fotos licenciadas com crédito exibido no app.
